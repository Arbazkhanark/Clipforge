# ClipForge
Creator clipping, collections, and Instagram publishing SaaS. Early development. Not deployed. Not production-ready.

Current status lives in `docs/PROJECT_CONTEXT.md`, `docs/FEATURE_STATUS.md`, `docs/ROADMAP.md`, and `docs/VERIFICATION.md`.
Also see `docs/PLAN.md`, `docs/ARCHITECTURE.md`, `docs/SETUP.md`, `docs/FIRST_RUN_CHECKLIST.md`, and `docs/COST_GUARDRAILS.md`.

Local sign-up and sign-in exist only in memory when `CLIPFORGE_LOCAL_AUTH=true` (refused in production). Demo screens use `CLIPFORGE_DEMO_MODE=true`. The default mode has no database session and no cloud storage.
